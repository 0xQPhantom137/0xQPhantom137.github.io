# 0xQPhantom137.github.io

My portfolio. Built from scratch in HTML, CSS, and vanilla JavaScript.

Live at **[0xqphantom137.github.io](https://0xqphantom137.github.io/)**

---

## why vanilla

I could have used React. I could have used Next.js. I could have spent three weeks configuring a build pipeline and felt productive without shipping anything.

Instead I wrote it using DeepSeek. Every line of HTML, every CSS rule, every JavaScript function. It's not the hardest way to build a portfolio. It's the way that means I actually know how my own site works.

---

## what's on it

- An about section
- A projects section
- A contact form
- Nothing else

No blog. No newsletter. No animations that make you wait four seconds to read a paragraph. Just the stuff that needs to be there.
